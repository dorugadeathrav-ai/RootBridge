# RootBridge
RootBridge is a full-stack e-commerce marketplace that bridges local producers with urban and global customers. Built using React, TypeScript, Node.js, Express, and PostgreSQL, it empowers farmers, artisans, and small businesses through secure digital commerce, seamless shopping, and modern technology

## Run With Go Live

Install dependencies and create the browser-ready build before starting Live Server:

```bash
npm install
npm run build
```

In VS Code, open the project folder, right-click `dist/index.html`, and choose **Open with Live Server**. The workspace is configured to serve the `dist` folder on port `5501`.

For development with automatic updates, use `npm run dev` and open `http://localhost:5173/` instead.
